# ADR 0001: 展示板 6 张卡换成本人内容（本地优先）

- 状态：已确认
- 日期：2026-09-26
- 决策人：仓库所有者（Robotwizardt）

## 背景

原项目（AT010303/Room_Portfolio）的展示板上有 6 个可点图标，
点击后镜头飞到对应设备，设备屏幕显示内容。原内容部分联网
（显示器/手机嵌作者 vercel 网站），部分是本地素材（电视 GBA、笔记本 mp3）。
所有者希望把这 6 张卡换成「自己的内容」。

## 决定

6 个图标的最终内容：

| 图标 | 内容 | 是否联网 |
|---|---|---|
| 显示器 desktop | iframe 嵌 B站 视频页 | 联网 |
| 手机 smartphone | 真交互地图（可拖拽缩放，Leaflet/高德） | 联网 |
| 电视 tv | 保留原超级马里奥 GBA 模拟器（暂不加游戏） | 本地 |
| 笔记本 laptop | 网易云音乐播放器：搜索点歌 + 歌词，调自建 API `http://101.35.40.219:3000` | 联网 |
| 音乐 music | 触发笔记本的网易云播放器 | 联网 |
| 主页 home | 退回房间全景（不变） | 本地 |

注：所有者最初要求「全部本地」，但 B站 / 网易云 / 真地图本质上必须联网。
已与所有者确认：接受「一部分本地、一部分联网」，并非真正全离线。

## 交互与呈现（相关决定）

- 点卡片：镜头飞到设备 + 同时弹出屏幕上的大面板（两个都要）。
- 卡片内容统一写在 `src/data/projects.js` 数据文件，改内容只动这一个文件。
- 不提供「打开链接」按钮。
- 面板界面用中文。
- 弹出大面板时，临时禁用 WASD 键盘移动（关闭后恢复）。
- 3D 设备屏幕里那一版内容只放「标题」（大字），描述留给大面板。

## 后果

- 需要新建/修改：projects.js、ProjectStore、ProjectPanel、各屏幕组件、
  dispItem.jsx 的点击行为、键盘组件的面板禁用逻辑。
- 断网时：电视（GBA）和主页仍可用；B站/地图/网易云不可用，属预期。
